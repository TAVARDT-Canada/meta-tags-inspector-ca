# Meta Tags and Open Graph Inspector

[![Meta Tags Inspector](https://img.shields.io/badge/TAVARDT-Meta%20Tags-5b3cf5.svg)](https://tools.tavardt.com/ca/meta-tags-checker/)
[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Metadata audit utility for Canadian digital channels, verifying search snippet eligibility, social sharing cards, and canonical links.

***

## Metadata and Social Card Audit Capabilities

* **Title and Description Inspection**: Evaluates title tag length and meta description boundaries for Canadian digital properties.
* **Open Graph Protocol Support**: Ensures complete og:title, og:description, og:image, og:url, and og:type parameters.
* **Social Sharing Preview**: Validates Twitter Cards and social graph protocols for multi-platform engagement.
* **Indexation Directives**: Analyzes robot meta tags and canonical target consistency.
* **Metadata Health Rating**: Clear 0 to 100 numerical evaluation highlighting priority content enhancements.

***

## Installation and Execution

Requires Python 3.8 or higher using standard library.

```bash
git clone https://github.com/TAVARDT-Canada/meta-tags-inspector-ca.git
cd meta-tags-inspector-ca
python meta_inspector.py example.ca
```

To output structured JSON:

```bash
python meta_inspector.py example.ca -json
```
